Ananta VLM Engine (Unlimited-Horizon Multi-Page)

End-to-end pipeline compressing 100+ document pages into 273 visual tokens per page with constant O(1) DASH attention.

1. DeepEncoder (Dual Visual Backbone) 16x Compression
Cascades SAM-ViT-B (stroke sharpness, boundaries, layout) and CLIP-L/14@224 (semantic character features).
Projector Downsampling (2048 to 1280)
2. Linear Projector Layer MlpProjector
Maps concatenated embeddings down to 1280 dimensions, emitting exactly 273 tokens per 1024x1024 page.
Token Embedding Stream
3. DeepSeek-V2 MoE Language Decoder 12 Layers / 64 Experts
Transformer layers with 64 routed + 2 shared experts. Dynamic Top-6 routing per token (~500M active parameters).
Hierarchical Sparse Attention
4. SR-SWA DASH Sparse Attention Bounded O(1) Memory
1.5-entmax differentiable block routing over 32-token summaries. Selects Top-12 remote blocks with 128-token local window.
Hardware Acceleration
5. Fused Triton Attention Kernel Custom GPU Kernel
Fuses gather indexing, additive block bias, softmax, and matrix multiplication in a single GPU pass.

Ananta Block Engine (Two-Stage Layout and Block OCR)

High-precision 37-class layout analysis paired with specialized per-block transcription across 22 Indic languages and English.

1. AnantaDocLayout (PP-DocLayoutV3) RT-DETR 33M
Document layout detector predicting 37 fine-grained classes with normalized bounding coordinates [0, 1000].
Pairwise Bilinear Projections
2. Antisymmetric Reading-Order Head Locality GCE
Calculates pairwise precedence matrix S[i,j] and decodes topological reading sequence via voting sort.
Geometry Deduplication and Area Clamping
3. Geometry Deduplication and Crop Normalization Area Clamp
Suppresses nested equation boxes within paragraphs and scales crop area into [256^2, 1536^2] pixels.
Specialized Prompt Dispatch
4. AnantaBlockOCR (Qwen3.5-0.8B VLM) 262k Vocab
Transcribes crops with targeted prompts for Prose, LaTeX Equations, and HTML Tables (colspan/rowspan).
Post-Processing
5. LaTeX Math Repair and Dehyphenation LaTeX Sanitizer
Protects Unicode Indic text inside math mode with \text{...} and rejoins hyphenated words across line breaks.

Ananta Hybrid Engine (Unified Co-Execution)

Combines structural layout segmentation with dynamic multi-engine dispatching for complex document portfolios.

1. Topological Layout Segmentation Segmentation
Decomposes document into structured spatial partitions with strict reading order sequence indexing.
Dynamic Content-Aware Routing
2. Intelligent Block Dispatcher Dual Dispatch
Routes formulas, tables, and Indic regional scripts to AnantaBlockOCR; passes global narrative to Ananta VLM.
Document Assembly
3. Document Synthesis Engine Reconstruction
Consolidates multi-modal outputs into a unified Markdown document with structured PageResult annotations.
